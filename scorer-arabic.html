Scoring System

Seven dimensions, each producing a 0–100 score. Dimensions combine sub-metrics where appropriate. Arabic-specific metrics use Arabic-aware LLM prompts or deterministic code over Arabic lexicons. The seven dimension scores feed a calibration-weighted Overall Score — equal-weighted by default, with all dimension and inner-metric weights adjustable via the Calibration tab. The Overall Score is then mapped to a CEFR band as an interpretation layer.

1 · Task Achievement

Did the response complete the task, meet length, and communicate the message?

WCC — Word Count Compliance

Scored 0–100 by comparing word count to the midpoint of the min/max range.

TA — Task Requirements

Each requirement marked PASS / FAIL using a strict test: response must name the topic AND give at least one specific detail.

Score = (PASS count + bonus) / (total + 1) × 100. Bonus for one extra developed on-topic point.

IE — Intelligibility & Effect

Scored 0–100 against a banded scale:

0–20 unintelligible · 21–40 barely intelligible · 41–60 partial · 61–75 mostly clear · 76–90 clear and effective · 91–100 fluent and compelling

TA dimension score = WCC × 0.40 + ((TA × 0.80) + (IE × 0.20)) × 0.60

2 · Content Quality

How well are ideas developed, supported, and extended?

CQ — Content & Ideas Markers

Each requirement scored 0–3:

0 absent · 1 mentioned · 2 developed (with reason / cause) · 3 extended (reason AND specific example)

Evidence is consumed once: a sentence used for requirement N cannot count for later requirements. The 4th "additional development" marker only credits semantically distinct ideas.

Score = sum / max possible × 100.

3 · Style & Register (Arabic-specific)

Is the writing in formal Modern Standard Arabic (MSA) appropriate for the task?

MSA Consistency

Holistic 0–100. Does the writing read as composed MSA or as transcribed speech / dialect?

Dialect Influence Detection

LLM-only severity classification. Detects markers from Gulf / Egyptian / Levantine / Maghrebi dialects. Severity → score:

none → 100 · isolated → 90 · moderate → 70 · pervasive → 40

Style & Register = MSA × 0.70 + Dialect × 0.30

4 · Language Range

How varied, flexible, and sophisticated is the language?

Vocabulary Diversity

Holistic 0–100. Range of distinct lexical items used (not penalised for derived forms of the same root).

Morphological Variety

Holistic 0–100. Evidence of masdar, active / passive participles, broken plurals, derived verb patterns.

Arabic Sentence Complexity

Holistic 0–100. Relative clauses, conditional sentences, nominal vs verbal sentence variety.

Language Range = Vocab × 0.334 + Morphology × 0.333 + Sentence × 0.333

5 · Organisation & Coherence (Arabic-specific · hybrid code + LLM)

Is the writing structured logically, with ideas linking and progressing clearly?

Arabic Cohesive Devices (code-only)

Deterministic scan of ~40 Arabic connectives across 6 categories: sequencing, addition, contrast, cause / effect, example, conclusion. Recognises و / ف clitic prefixes (وأيضاً، فلذلك).

Score rewards variety and category spread, NOT raw frequency (to prevent mechanical stuffing).

Cohesive Devices = (categories used / 6) × 60% + (distinct types / 10) × 40%

Coherence & Flow (LLM)

Holistic 0–100. Scope-locked to logical progression, paragraph flow, idea linking, and progression clarity. Explicitly excludes vividness, engagement, style, and fluency (those belong to S&R and IE).

Organisation & Coherence = Cohesive Devices × 0.30 + Coherence & Flow × 0.70

6 · Language Accuracy

Is the language controlled and accurate enough for clear communication?

Grammar & Language Control

Holistic 0–100. Measures COMMUNICATIVE control, NOT native-speaker perfection.

Focus on: sentence formation, agreement, verb forms and tense, grammatical consistency, whether errors interfere with understanding.

Does NOT penalise: missing case endings (إعراب), minor spelling variation, stylistic preference.

Banded scale:

0–20 errors block understanding · 21–40 frequent basic errors · 41–60 noticeable but understandable · 61–80 good control · 81–100 strong consistent control

7 · Orthographic Control (Arabic-specific · hybrid code + LLM)

Does the writing demonstrate correct Arabic spelling, hamza placement, taa marbuta usage, and script consistency? Scored as a distinct construct from grammar — a learner may control grammar while still producing recurring orthographic errors.

Technical Quality (code-only)

Deterministic hygiene checks across four sub-scores, each 0–100, averaged:

Arabic Punctuation Usage · Whitespace & Formatting · Tatweel Abuse · Non-Arabic Character Intrusion

Common Error Detection (code-only)

Deterministic lexical comparison against four curated lists of high-frequency Arabic learner errors: Taa Marbuta (ة/ه), Alif Form (ا/ى/أ/إ), Common Hamza, and General Spelling. Confidence-tiered entries (always_wrong / usually_wrong) with a proper-noun gate to protect personal names (e.g. علي as a name vs على as a preposition).

Per-category score = max(0, 100 − errors-per-100-words × 8) · composite = mean of 4 categories

LLM Orthographic Accuracy

Scope-locked AI judgement on orthographic correctness that cannot be measured reliably by code — in-context hamza placement, taa marbuta in non-listed words, general spelling beyond curated patterns, and overall orthographic consistency. Letter-form distribution and deterministic flags are passed as prompt context so the LLM focuses on what the lists missed. Banded scale:

93–100 near-native / elite control · 87–92 strong with advancing mastery · 81–86 strong stability · 61–80 generally accurate · 41–60 unstable · 21–40 persistent problems · 0–20 severe

Deterministic Ceiling

The deterministic combined score is capped to prevent clean-but-unremarkable writing from drifting into elite territory:

Without advanced orthographic evidence → cap at 88 · With advanced evidence (≥3 distinct of ئ / ؤ / ء / آ AND ≥3 per 100 words) → cap at 96

Absence of errors alone does not earn an upper-band score; positive evidence of advanced control is required. Topics that do not naturally elicit advanced hamza environments may produce capped scores — a known limitation under review for marker calibration.

10-Word Floor

The dimension returns N/A* below 10 words (lower than the system-wide 30-word floor — orthography can be assessed on very short responses where most other dimensions cannot).

Orthographic Control = Technical Quality × 0.10 + Common Error Detection × 0.40 + LLM Orthographic Accuracy × 0.50 (default — adjustable via Calibration tab)

Band Pressure Rules

Each LLM prompt has explicit construct-based rules to prevent compression of the score scale. These are NOT CEFR labels — they're behavioural caps on what each band requires.

Short-response caps

Word count and expected word range are passed into every LLM scoring prompt. Very short responses with simple SVO patterns are capped low so simple-but-clean writing doesn't inflate into mid-bands. Approximate caps for short + simple responses:

Vocab 30 · Morph 25 · Sentence 25 · Coherence & Flow 40 · Grammar 30 (very short) / 45 (below expected range)

Ceiling blockers (81+ entry gates)

Each metric defines what prevents a score above 81: repetition, narrow scope, lack of subordination, paragraph absence, etc. Reaching the upper band requires positive evidence, not just "no obvious errors".

Flexibility pressure (A2 / B1 separation)

Vocab and Sentence Complexity prompts treat range as flexibility and precision, not presence of features. Recycled common verbs (ذهبنا، أكلنا، رجعنا), predictable sequencing, and formulaic sentence structures stay in lower or mid bands even when grammatically clear. A response with 30 distinct words but the same 3-4 narrative verbs is mid-band.

Complexity-conditioned accuracy (B1 / B2 / C1 separation)

Grammar & Language Control distinguishes "low error rate" from "control under complexity". If 2 or more of these "mostly simple" signals are true, the score is capped at 75:

only past or only present tense throughout · zero or one subordinate clause · every sentence is SVO or و / ثم coordination · no embedded clauses · same handful of verb forms recycled

85+ evidence rule

Scores above 85 require active demonstration of advanced performance: developed ideas, precise vocabulary, controlled structural variety, mature organisation, accuracy across complex language. Length alone is not sufficient.

Overall Score & CEFR Band

The seven dimension scores combine into a single Overall Score using calibration-weighted averaging. Default weights are equal (≈ 14.3 % per dimension); adjustments are made in the Calibration tab and persist across sessions. The Overall is then mapped to a CEFR band as an interpretation layer — the metrics themselves remain construct-based and are not CEFR-anchored. Disabled dimensions are excluded from the Overall and the remaining enabled dimensions' weights are renormalised proportionally.

Overall = calibration-weighted sum(TA, CQ, S&R, Lang Range, Org & Coh, Lang Acc, Orth Ctrl) — default: equal weight (≈ 14.3 % each)

Determinism & Providers

All LLM calls use temperature: 0 for repeatable scoring on identical input.

Supported providers: OpenAI (gpt-5, gpt-5-mini, gpt-4o, gpt-4o-mini, gpt-4.1, gpt-4.1-mini) and Anthropic (Claude Sonnet 4.6, Opus 4.6, Haiku 4.5). Provider is selected via the header dropdown. API keys are held server-side; the browser never sees them.

Throttle toggle: When enabled (default ON), caps in-flight API calls at 1 concurrent with a 3.5-second release delay to stay under provider rate limits (e.g. Anthropic Tier 1 = 30K input tokens/min). 429 errors are retried with a 35-65 second backoff that honours Retry-After headers.

30-word minimum: Each LLM metric returns null on responses below 30 words; the deterministic Cohesive Devices code does the same. The results table shows N/A* for any blocked metric. The Overall Score is computed from whichever dimensions are valid; if none are valid, Overall itself is N/A*.

Summary

V1 = 7 dimensions. Hybrid code + LLM scoring throughout: deterministic code where reliable (word count compliance, cohesive devices, orthographic technical quality and error detection), scope-locked LLM judgement where context matters. Two dimensions — Organisation & Coherence and Orthographic Control — explicitly combine code and LLM sub-scores. Construct-based scoring with band pressure rules and dimension-level ceilings; CEFR mapping applied only at the interpretation layer.

All metrics return 0–100. Each dimension is reported separately with justification. The Overall Score is the calibration-weighted average of all enabled dimensions (default: equal weight ≈ 14.3 % each across 7) and is the input to the CEFR badge.

Arabic-specific metrics (MSA, Dialect, Cohesive Devices, all four Orthographic Control sub-metrics) use Arabic lexicons and Arabic-aware prompts. Other metrics reuse English scoring patterns with Arabic content as input.

Calibration

Tune the weight each dimension carries in the Overall Score, and the weight each metric carries within its dimension. Changes save automatically and apply on the next Run Scoring.
